Privacy policy

mcp-google-multi (personal) · effective 3 October 2026

This OAuth client is used only by its owner, Nelle Pabellan, to reach the owner's own Google accounts.

  • What is accessed: Gmail, Calendar, Drive, Docs, Sheets, Slides, Forms, Contacts, Meet, Chat and Apps Script data in the owner's own accounts, only at the scopes the owner approves.
  • Where it goes: Data is handled by software running on the owner's own computer. OAuth tokens are stored there, encrypted at rest. Nothing is sent to any server run by this app, because there isn't one.
  • Sharing: No data is sold, shared or used for advertising. Use of Google user data follows the Google API Services User Data Policy, including its Limited Use requirements.
  • Removal: Access can be revoked at any time at myaccount.google.com/permissions.
